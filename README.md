## hft-for-dummies + backtester

`hft-for-dummies/` is the Rust SOL-USD market maker from
[bulletxyz/hft-for-dummies](https://github.com/bulletxyz/hft-for-dummies)
(upstream commit `11ba8eb`), plus `fetch-binance`, `record` and `backtest`
commands. See its README's *Backtesting* section.
